# YouTube Video Downloader

A clean, Apple-style GUI for [yt-dlp](https://github.com/yt-dlp/yt-dlp) on Windows.

## Features

- Paste a YouTube URL and download with one click
- Select quality: Best / 1080p / 720p / Audio Only (MP3)
- Real-time download progress and speed display
- Proxy support (HTTP / SOCKS5)
- Built-in yt-dlp updater
- Clean, minimal interface

## Requirements

- Windows 10 or later
- [yt-dlp.exe](https://github.com/yt-dlp/yt-dlp/releases) (place in the same folder)
- [ffmpeg.exe](https://ffmpeg.org/download.html) (optional, for format merging)

## Quick Start

1. Download `yt-dlp.exe` from the [official releases page](https://github.com/yt-dlp/yt-dlp/releases) and put it in this folder.
2. (Optional) Download `ffmpeg.exe` and put it here too for best quality merging.
3. Double-click `启动图形下载器.bat` to launch.
