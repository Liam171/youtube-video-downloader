  YouTube 视频下载器 — 使用说明
════════════════════════════════════════

【启动方法】
双击「启动图形下载器.command」即可。

【首次打开如果被 macOS 拦截】
网络下载的文件第一次运行会被系统拦一下：

  方法一（推荐）：右键点击「启动图形下载器.command」
                → 选「打开」→ 弹窗里再点「打开」。
                （只做这一次，之后双击就能直接启动）

  方法二：打开「终端」，粘贴下面这行回车：
    xattr -d com.apple.quarantine ~/Downloads/YouTube下载器/启动图形下载器.command
  （路径按实际存放位置改）

【第一次启动可能弹出的对话框】
· 弹出 "PySide6 is not installed" → 点 Install，自动安装，等它跑完即可。
  （如果提示安装失败：先打开终端运行 xcode-select --install，
    再手动执行 python3 -m pip install pyside6）
· 本压缩包已内置 yt-dlp 和 ffmpeg，不需要装 Homebrew。

【怎么用】
1. 粘贴视频链接
2. 选择画质（Best / 1080p / 720p / 仅音频 MP3）
3. 点 Start Download
文件默认保存到「下载」文件夹，想换位置点 Browse…。

【常见问题】
· 下载失败显示 403：YouTube 风控，换个视频或过会儿再试。
· 更新 yt-dlp：点界面上的 Update yt-dlp 按钮。
· 下载记录只存在本地 config.json，不会上传任何数据。
